# 회사 조직·급여 관리 실습

[`training_04.py`](./training_04.py)는 회사, 부서, 사원, 급여, 근무이력을 객체로 나누어 관리하는 객체지향 프로그래밍 실습입니다.

## 배운 내용

- **클래스별 책임 분리**: 급여 계산은 `Salary`, 경력 계산은 `WorkHistory`와 `Employee`, 조직 집계와 보고서 출력은 `Department`와 `Company`가 담당합니다.
- **객체 포함 관계(has-a)**: 클래스가 다른 객체를 속성으로 보유합니다. 상속 대신 객체와 리스트를 조합해 조직을 표현합니다.
- **1:N 관계**: 회사는 여러 부서를 `departments` 리스트에, 부서는 여러 사원을 `employees` 리스트에, 사원은 여러 근무이력을 `histories` 리스트에 보관합니다.
- **1:1 관계**: 각 사원은 `Salary` 객체 하나를 `salary` 속성으로 가집니다.
- **객체 간 책임 위임**: 회사가 급여를 직접 계산하는 대신 부서에 요청하고, 부서는 사원의 `Salary` 객체에 총액 계산을 요청합니다.
- **리스트 집계와 빈 목록 처리**: 급여·사원 수·경력을 리스트에서 합산합니다. 사원이 없는 부서의 평균 경력은 0으로 처리해 0으로 나누는 오류를 피합니다.

## 클래스 역할

| 클래스 | 주요 데이터 | 주요 기능 |
|---|---|---|
| `Salary` | 기본급, 상여금, 야근수당 | 총액, 세금(총액의 10%), 실수령액 계산 |
| `WorkHistory` | 회사명, 직급, 시작·종료 연도 | 근무 연수 계산 및 이력 문자열 생성 |
| `Employee` | 이름, 부서명, 급여 객체, 근무이력 목록 | 이력 추가, 총 경력 계산, 급여명세 문자열 생성 |
| `Department` | 부서명, 사원 목록 | 사원 배치, 급여 합계·평균 경력 계산, 사원 명세 출력 |
| `Company` | 회사명, 부서 목록 | 전체 사원 수·급여 계산, 부서별 보고서 출력 |

## 객체 생성 및 보고서 흐름

1. `Salary` 객체를 만들고 `Employee(name, salary)`로 사원을 생성합니다. 사원의 부서명은 처음에는 빈 문자열입니다.
2. `Employee.add_history()`로 근무이력을 추가합니다. 근무이력이 없는 신입 사원의 경력은 0년입니다.
3. `Department.add_employee()`로 사원을 배치합니다. 이 메서드가 사원의 `dept` 속성을 부서명으로 지정하고 목록에 추가합니다.
4. `Company.add_department()`로 부서를 회사에 등록합니다.
5. `Company.print_report()`가 각 부서의 `print_members()`를 호출한 뒤 전체 사원 수와 급여 합계를 출력합니다.

## 예시 결과

실습 데이터의 부서별 합계는 다음과 같습니다.

| 부서 | 인원 | 급여 총액 | 평균 경력 |
|---|---:|---:|---:|
| 개발팀 | 2명 | 775 | 9.0년 |
| 인사팀 | 1명 | 390 | 4.0년 |
| 영업팀 | 1명 | 350 | 0.0년 |
| 마케팅팀 | 1명 | 385 | 3.0년 |
| 전체 | 5명 | 1900 | — |

급여 금액은 실습 데이터의 단위(만원)를 사용합니다. 보고서에는 부서별 사원 수, 급여 합계, 평균 경력과 사원별 총액·세금·실수령액이 표시됩니다.

## 실행

```bash
python training_04.py
```

## 현재 실습의 처리 범위

- 부서에 배치되지 않은 사원은 `dept`가 빈 문자열이며 부서 보고서에 나타나지 않습니다.
- 한 사원을 여러 부서에 추가하는 것을 막지 않습니다. 부서 목록에는 여러 번 들어갈 수 있고, `dept`는 마지막으로 추가된 부서명으로 바뀝니다.
- 종료 연도가 시작 연도보다 빠른 경우와 음수 급여 항목은 검증하지 않습니다.
